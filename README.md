# Employee Management Mini-App

Production-quality employee management app built for a technical assessment. Angular (standalone components) frontend, NestJS backend, PostgreSQL database — designed to stay fast at 10,000+ employee records via server-side pagination, search, filtering, and SQL aggregation.

> This README is filled in incrementally as each phase of the build lands (see git history). Sections below are placeholders until the corresponding phase is complete.

## Tech Stack
- Frontend: Angular (standalone components, Reactive Forms)
- Backend: NestJS (TypeScript)
- Database: PostgreSQL
- ORM: TypeORM (migrations, QueryBuilder) — see "Architecture" for rationale
